# Creation Engine (`creation_engine/`)

Single place for **Rhea** direction, governance, and project assessment logs. **Current governance:** `rhea-governance-agent.md` — check the file header for **v3.x** (source of truth).

| File | Role |
|------|------|
| `rhea-governance-agent.md` | Agent law: **c = e s i²**, Iteration Close, Error & Debug, **Visual / layout triage**, insight timestamps, changelog (line-budget enforced). |
| `rhea-governance-changelog-archive.md` | Older **v1–v3.6** changelog rows + **Observed Effect** history. |
| `rhea-creation-intent.md` | **Sticky template**, **current** intent, **history** by project. |
| `rhea-insights.md` | Bookmarked + session insights; **YYYY-MM-DD HH:MM TZ** on new blocks. |
| `rhea-stack-directive.md` | **One** canonical app stack for all repos in this monorepo (verify `package.json` per app). |
| `grubgauge-build-assessment.md` | GrubGauge **canonical rollup** at top — Vercel Root, vertical text / width contract, mileposts. |
| `clarity-build-assessment.md` | Clarity — assessments **historical** (protocol version as cited in each entry). |
| `daily-anchor-build-assessment.md` | Daily Anchor — same. |

**Start here for agents:** (1) `rhea-insights.md` → (2) `rhea-creation-intent.md` (current intent) → (3) active project `*-build-assessment.md` → (4) `rhea-governance-agent.md` when enforcing protocol.
